# Travsior — Modern International Mobility Platform

> **Your Way Abroad Starts Here.**  
> Travsior is a high-conversion, student-first study abroad and visa consultancy web application engineered with Next.js 14, TypeScript, Tailwind CSS, and full WCAG 2.2 AA accessibility standards.

## 🚀 Key Features

- **High-Conversion Hero & Pathways:** Dual-funnel discovery for Study Abroad and Visit Visas with transparent, direct conversion actions.
- **Interactive Eligibility Assessment Calculator:** 3-step dynamic feasibility checker for students to calculate GPA, budget, destination, and intake fit.
- **Country & Program Deep-Dives:** Structured breakdown of top destinations (UK, Australia, Canada, USA, Germany, Ireland, Italy, UAE) highlighting tuition models, PSW regulations, and scholarships.
- **Transparent 5-Stage Process Roadmap:** Clear, milestone-oriented execution timeline from profile discovery to pre-departure briefing.
- **Accessible Free Consultation Booking Modal:** Keyboard-navigable (`Escape` close, focus ring trap), screen reader accessible with instant WhatsApp integration.
- **100% WCAG 2.2 AA Compliant:** Calibrated color palette (`#0958D9` royal blue with >6.1:1 contrast, `#047857` emerald with >5.4:1 contrast, explicit form labeling, and zero layer/contrast collisions).

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, Server Components & Static Site Generation)

- **Icons:** [Lucide React](https://lucide.dev/)

- **Deployment:** Vercel-ready with zero-config build pipeline

## 🏁 Getting Started

### Prerequisites

- Node.js 18.17+ or 20+
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sultanofficial717/travisor.git
   cd travisor
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🏗️ Production Build & Verification

```bash
# Typecheck
npx tsc --noEmit

# Production Build
npm run build

# Start Production Server
npm run start
```

## 🌐 Deploy to Vercel

This repository is pre-configured for one-click deployment to [Vercel](https://vercel.com):

1. Push your changes to GitHub.
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import `sultanofficial717/travisor`.
4. Framework Preset will auto-detect **Next.js**.
5. Click **Deploy**.
